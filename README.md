# Rubesh Kumar — Video Editor Portfolio

This is a static website package for GitHub Pages. It uses plain HTML, CSS and JavaScript; no build step is needed.

## Publish with GitHub Pages

1. Upload `index.html`, `style.css`, `script.js` and this README to the root of your repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select your publishing branch (usually `main`) and the root folder, then save.
4. GitHub Pages will show the site URL after it finishes publishing.

The showreel space below Rubesh’s name is intentionally empty for now. Add the showreel when it is ready. The work section currently contains the 23 video links shared for the portfolio. Make sure each Google Drive video is viewable by anyone with its link so visitors can open it.

The page loads fonts from Google Fonts and video thumbnails from their linked services when online. Nothing in this package has been published.
